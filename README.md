## 🚀 How to Run Locally

Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Brave).

Alternatively, you can run a local development server using Python:

```bash
# In this directory:
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

## 🌐 How to Deploy for Free

### Option 1: GitHub Pages (Recommended)
1. Create a GitHub repository named `subhbishnoi.github.io` (or any repo name like `portfolio`).
2. Push the files in this directory to the repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/subhbishnoi/subhbishnoi.github.io.git
   git push -u origin main
   ```
3. Go to **Settings > Pages > Branch: main > Save**.
4. Your site will be live at `https://subhbishnoi.github.io`!

### Option 2: Vercel / Netlify
1. Go to [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. Drag and drop this `portfolio` folder directly onto the dashboard.
3. Your portfolio goes live instantly with a free SSL certificate!
